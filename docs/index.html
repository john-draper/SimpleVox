A focused four-stage pipeline.

From raw video to a clean final cut — each stage is purpose-built and runs entirely on your machine.

🎙️
Stage 1

Transcribe

WhisperX generates GPU-accelerated word-level timestamps

🔍
Stage 2

Detect

A customizable dictionary finds words to replace with euphemisms

🗣️
Stage 3

Generate

Microsoft Edge neural TTS speaks each clean replacement word

✂️
Stage 4

Splice & Mux

ffmpeg seamlessly merges the clean audio with the original video

🎯

Word-Level Precision

Forced alignment technology gives accurate per-word timestamps, so only the targeted words get replaced — nothing more.

⚡

GPU Accelerated

WhisperX runs on CUDA GPUs for fast transcription. Batch processing handles entire show folders at once.

🔗

Seamless Splicing

Each replacement is time-stretched, trimmed, and loudness-matched to fit perfectly. No audible gaps or artifacts.

🎨

Lossless Video

The original video stream is copied bit-for-bit. Only the audio track is edited — picture quality stays identical.

🔧

Fully Customizable

Edit the euphemism dictionary, swap voices, or change Whisper models. Every part of the pipeline is configurable.

💚

100% Open Source

MIT licensed, no subscriptions, no telemetry, no lock-in. Run it locally on your own hardware, forever.

🗣️

One clear, natural voice

Every replacement word is spoken by Microsoft Edge neural TTS — a high-quality, conversational male voice that blends in naturally. Prefer a different tone? Choose from US, British, or Australian accents with a single flag.

🔒

Private & local

Your video never leaves your machine. All processing happens locally — no cloud uploads, no data collection, no API keys required.

Quick Start.

Up and running in three commands.

# Clone the repo $ git clone https://github.com/john-draper/SimpleVox.git $ cd SimpleVox # Install dependencies $ pip install -r requirements.txt # Drop a video into input/, then run: $ python run.py "input/movie.mkv" # Result: output/movie.mkv (censored audio + original video)

Questions?

Everything you might want to know.

What video formats are supported?

Any format that ffmpeg can decode: MKV, MP4, M4V, MOV, AVI, WebM, WMV, and FLV. The pipeline outputs the same container format as the input, so it drops right back into your library.

Do I need a GPU?

A CUDA-compatible NVIDIA GPU is strongly recommended — WhisperX transcription is dramatically faster on GPU. The pipeline does fall back to CPU automatically, but expect it to take significantly longer.

Do I need any API keys?

No. SimpleVox uses Microsoft Edge TTS, which is free and requires no authentication. There's no HuggingFace token, no ElevenLabs key, no cloud account — just install and run.

Can I customize which words get filtered?

Absolutely. The profanity dictionary is a plain Python dict in replacements.py — add or remove mappings, change euphemisms, or tweak hyphenated variants. It's fully editable.

Is the video quality affected?

No. The original video stream is stream-copied losslessly (-c:v copy). Only the audio track is edited and re-encoded. The output picture is byte-for-byte identical to the source.

Can it process a whole folder of videos?

Yes. Pass a folder (or run with no arguments to default to input/) and SimpleVox will process every video recursively, mirroring your folder structure into output/.
