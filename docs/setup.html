Setup Guide

Get SimpleVox running on your machine in a few minutes.

Prerequisites

Three things to install before you begin:

1. Python 3.10+

Download from python.org or install via your package manager. Make sure Python is on your PATH.

2. ffmpeg

ffmpeg handles audio decoding, splicing, and video muxing. Install it with:

# Windows (PowerShell / winget) $ winget install Gyan.FFmpeg # macOS (Homebrew) $ brew install ffmpeg # Ubuntu / Debian $ sudo apt install ffmpeg

After installing, reopen your terminal and run ffmpeg -version to confirm it's on your PATH.

3. NVIDIA GPU (recommended)

A CUDA-compatible NVIDIA GPU makes transcription dramatically faster. SimpleVox falls back to CPU automatically if you don't have one, but it will be much slower for long videos.

Installation

Step 1 — Clone the repository

$ git clone https://github.com/john-draper/SimpleVox.git $ cd SimpleVox

Step 2 — Install PyTorch (GPU only)

For GPU acceleration, install PyTorch matching your CUDA version first, before the other dependencies. The example below is for CUDA 11.8:

$ pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118

For other CUDA versions, see the PyTorch install guide. If you're running on CPU only, you can skip this step.

Step 3 — Install the remaining dependencies

$ pip install -r requirements.txt

This installs WhisperX, edge-tts, and audio processing libraries. No HuggingFace token or any other API key is required.

Usage

Place your videos

Drop video files into the input/ folder. Subfolders are supported — their structure is mirrored into the output directory:

input/ ├── movie.mkv └── Season 1/ └── episode 01.mkv

Run the pipeline

# Process the whole input/ folder (recursive): $ python run.py # Single file: $ python run.py "input/movie.mkv" # A whole folder (recursive): $ python run.py "input/Season 1" # Choose a different generic voice: $ python run.py "input/movie.mkv" --voice en-US-DavisNeural # Use a more accurate (slower) Whisper model: $ python run.py "input/movie.mkv" --model large-v3 # Skip videos that already have an output file: $ python run.py --skip-existing # Keep going even if one video fails (batch mode): $ python run.py --continue-on-error # Windows launcher (pass-through wrapper): > run.bat > run.bat "input\Season 1"

Output

The censored video is saved to output/ with the same filename as the input and the same relative folder structure. Intermediate files (transcription JSON, replacements JSON, generated WAVs) are stored under output/_intermediate/:

output/ ├── movie.mkv ← censored output ├── Season 1/ │ └── episode 01.mkv ← censored output └── _intermediate/ ├── movie.json ├── movie_replacements.json └── Season 1/ └── episode 01.json

Filenames with spaces, !, &, and other special characters are handled correctly — all discovery happens in Python to avoid shell-quoting issues.

Configuration (optional)

SimpleVox works out of the box with no configuration. To tune transcription or muxing behavior, copy .env.example to .env and edit the values:

# Windows > copy .env.example .env # macOS / Linux $ cp .env.example .env
VariableDefaultDescription
WHISPER_DEVICEcudacuda or cpu
WHISPER_MODELsmallWhisper model size
VIDEO_REENCODE0Set to 1 to re-encode the video stream (fallback)

Troubleshooting

Audio out of sync

SimpleVox time-stretches each replacement to exactly match the original word's duration. If you still see drift, make sure you're using the latest splice_audio.py.

CUDA crashes / cuDNN errors

Install cuDNN 8 DLLs and copy them to your torch/lib/ folder:

$ pip install nvidia-cudnn-cu11==8.9.4.25

Or fall back to CPU with --device cpu.

FFmpeg not found

Reinstall ffmpeg (see prerequisites above), then reopen your terminal so the PATH changes take effect.

edge-tts returns tiny or empty audio

This is usually a transient network issue — just rerun. The generation stage skips already-generated files with --skip-existing, so you won't redo any work.
